# 🐣 구구단 놀이

초등학교 저학년 아이들이 구구단을 외우도록 돕는 웹 페이지입니다.

- 화면에 구구단 문제(예: `7 × 8 =`)가 랜덤으로 나오고, **"칠 곱하기 팔은?" 하고 소리로 읽어 줘요.**
- 틀리면 "칠 팔 오십육"처럼 정답을 소리로 외워 줘요. (소리는 시작 화면이나 게임 중 🔊 버튼으로 끌 수 있어요)
- 아이가 **소리 내어 답을 말하면** 바로 ⭕ / ❌ 로 알려 줘요. (숫자 버튼이나 키보드로 답해도 돼요)
- **📖 순서대로 외우기**: 한 단을 골라 ① "칠 이 십사"를 듣고 따라 말하고, ② 답을 가린 채 순서대로 말해 봐요. 다 외우면 그 단만 섞어서 문제를 풀 수 있어요.
- 맞히면 10점, 3초 안에 맞히면 5점을 더 받아요. 연속으로 맞히면 🔥 연속 기록이 올라가요.
- 다 풀면 점수와 별(⭐), 틀린 문제 목록을 보여 줘요. 최고 점수는 그 기기에 저장돼요.

## 🎯 보스크 AI로 알아듣기 (선택)

시작 화면 ④번에서 말을 알아듣는 방법을 고를 수 있어요.

| | 🌐 구글 (기본) | 🎯 보스크 AI |
|---|---|---|
| 어디서 알아듣나 | 구글 서버 | **휴대폰 안** ([Vosk](https://alphacephei.com/vosk/) 한국어 모델) |
| 목소리 | 구글로 보내져요 | 휴대폰 밖으로 안 나가요 |
| 알아듣는 말 | 아무 말이나 | **숫자만** (엉뚱한 글자로 받아 적지 않아요) |
| 준비 | 없음 | 처음 한 번 AI 파일 받기 (87MB, 와이파이 추천) |

- 보스크는 [vosk-browser](https://github.com/ccoreilly/vosk-browser)로 브라우저 안에서 돌아가요.
- 한국어 모델 파일: `models/vosk-model-ko.tar.gz` (원본: vosk-model-small-ko-0.22, Apache 2.0 라이선스)
- 처음 받은 뒤에는 브라우저 저장 공간에 저장돼요. 시크릿 창에서는 저장 공간이 부족해서 안 될 수 있어요.

## 실행하는 방법

파일은 `index.html` 하나뿐이에요.

1. **가장 쉬운 방법**: `index.html` 파일을 크롬(Chrome) 브라우저로 열기
2. **인터넷 주소로 쓰기 (GitHub Pages)**:
   저장소 → Settings → Pages → Branch 를 이 브랜치로 고르고 Save →
   잠시 뒤 나오는 주소(`https://아이디.github.io/99dan/`)로 접속

## 말로 답하기 안내

- 크롬, 엣지, 사파리(아이폰/맥)에서 됩니다. 파이어폭스는 안 돼요 → 숫자 버튼을 쓰세요.
- 처음 시작하면 "마이크를 사용할까요?" 라고 물어봐요. **허용**을 눌러 주세요.
- `21`, `이십일`, `스물하나`, `이십일이요` 처럼 말해도 알아들어요.
